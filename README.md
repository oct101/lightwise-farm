# LIGHTWISE FARM

เว็บโครงงาน **LIGHTWISE FARM** — โรงเรือนปลูกพืชในร่ม 2 ชั้น จากท่อ PVC
ควบคุมหลอดไฟ 3 สี พัดลมแยกชั้น และปั๊มน้ำ ด้วย ESP32

## อ่านค่าจริงจากเครื่อง

หน้าแดชบอร์ดอ่านค่าจาก ESP32 ได้ตรง ๆ ผ่าน **Web Serial** ไม่ต้องพึ่ง WiFi หรือคลาวด์

1. เสียบสาย USB จากบอร์ดเข้าคอมพิวเตอร์
2. เปิดหน้าเว็บด้วย **Chrome หรือ Edge บนคอมพิวเตอร์**
3. กด **เชื่อมต่อ ESP32 ผ่าน USB** แล้วเลือกพอร์ต
4. เลือกโหมด `AUTO` เพื่อให้ระบบทำงานเอง หรือ `MANUAL` เพื่อกดสั่งเอง

> ปิด Serial Monitor หรือโปรแกรมอื่นที่จับพอร์ตไว้ก่อน เพราะพอร์ตเปิดได้ทีละโปรแกรม

## ระบบทำอะไรได้

- วัดอุณหภูมิ **แยกทีละชั้น** ด้วย DS18B20 กันน้ำ 2 ตัว
- วัดอุณหภูมิ ความชื้นอากาศ (DHT22) และความเข้มแสง (BH1750)
- เปิด–ปิดหลอดสเปกตรัม เหลือง เขียว แยกกันได้ทีละดวง → **เปลี่ยนสูตรสีแสงได้ 6 แบบ**
- พัดลม **แยกชั้น** เปิดตามอุณหภูมิของชั้นนั้นเอง (29 °C เปิด / 27 °C ปิด)
- ปั๊มน้ำตามตารางเวลา 07:00 / 12:00 / 17:00 ครั้งละ 20 วินาที
- สตริป SK6812 RGBW 30 ดวง ปรับอัตราส่วนแดง:น้ำเงินได้ 4 สูตร
- สวิตช์หน้ากล่อง AUTO / OFF / MANUAL
- บันทึก CSV ทุกนาทีสำหรับทำกราฟผลการทดลอง
